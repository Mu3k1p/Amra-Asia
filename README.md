# Amra

Static website for Amra Café on Koh Dach. Plain HTML, CSS and images, no build step.

- Pages: index.html, menu.html, visit.html
- Styles: style.css (Jost, Poppins, Fira Sans)
- Photos: images/
- Deploy on Vercel with Framework Preset set to Other and no build command.

Never commit tokens or keys to this repo.
